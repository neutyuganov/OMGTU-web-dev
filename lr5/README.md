# Лабораторная работа 5 — Список товаров с фильтрами

Загрузка товаров через `fetch` (fakestoreapi.com) в `useEffect` с `AbortController`, фильтрация по категории и диапазону цены на клиенте, состояния загрузки и ошибки.

Запуск:
```
npm install
npm run dev
```
(с включённым VPN: `npm run dev -- --host 127.0.0.1`)
